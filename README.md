# omnistream

## Autenticación

El proyecto usa `https://thnrfbomvckokqoyoehq.supabase.co` como URL predeterminada. Define `window.OMNISTREAM_SUPABASE_ANON_KEY` antes de cargar la aplicación con la clave anon/public de este proyecto. También puedes sobrescribir la URL mediante `window.OMNISTREAM_SUPABASE_URL`. No uses una clave `service_role` en el navegador. Sin la clave anon, el inicio de sesión con correo y contraseña usa cuentas locales en este navegador; las contraseñas se guardan como hashes PBKDF2 con sal.

Con la clave configurada y Google habilitado como proveedor de autenticación en Supabase, el botón inicia el flujo OAuth real. Supabase guarda la sesión en `localStorage` y la restaura al volver del proveedor. Añade `https://thnrfbomvckokqoyoehq.supabase.co/auth/v1/callback` como URI de redirección autorizada en Google Cloud y permite la URL del sitio en las URL de redirección de Supabase Auth. Sin la clave anon, el botón de Google informa que falta configuración; no simula una identidad.

## Subida de videos

Ejecuta `schema.sql` en el SQL Editor de Supabase para crear los buckets privados y las tablas `public.videos`, `public.channel_profiles`, `public.media_clips`, `public.subscripciones`, `public.video_reactions`, `public.video_comments` y `public.video_bookmarks`, además de sus políticas. El script también añade a `public.videos` los campos `thumbnail_url` y `thumbnail_path`; vuelve a ejecutarlo en instalaciones existentes para aplicar esta actualización. Los videos se guardan bajo una carpeta con el ID del usuario; los metadatos incluyen título, descripción, visibilidad, contador de reproducciones y la ruta del archivo (`video_path`). Al publicar se puede indicar una URL de portada; si se deja vacía, se genera una miniatura JPEG del primer fotograma y se guarda de forma privada junto al video. Como el bucket `videos` es privado, la aplicación genera URLs firmadas para reproducir el contenido y no expone URLs públicas que pudieran saltarse la visibilidad. Las miniaturas se muestran en el feed, los perfiles de canal y los videos sugeridos. La vista de reproducción dedicada incluye recomendaciones, datos y perfil del canal, suscripción, votos, comentarios y guardados. Los votos, comentarios y guardados se asocian al usuario autenticado y al video; los comentarios se ordenan cronológicamente y solo su autor o el dueño del video puede eliminarlos. Tras publicar un video se puede abrir Clipper Studio para guardar un clip vertical ligado a su ID. Los perfiles públicos muestran información del canal, estadísticas y pestañas de videos y clips; los clips solo son visibles públicamente cuando pertenecen a un video público. La tabla de suscripciones solo permite consultar y modificar las suscripciones propias; el total público se obtiene mediante la función `public.contar_suscriptores`.
